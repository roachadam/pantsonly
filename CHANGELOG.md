# Changelog

All notable changes to this project are documented here. Versions follow
Semantic Versioning.

## 1.0.0 - 2026-09-10

- Renamed the extension to PantsOnly - Block YouTube Shorts.
- Added a shared Firefox and Chromium build pipeline.
- Added store-ready icons and browser-specific packages.
- Reduced generated CSS size and full-document revalidation work.
- Removed the unnecessary `tabs` permission and narrowed YouTube access to HTTPS.
- Added public project, privacy, security, and release documentation.
- Added resilient Shorts shelf, card, navigation, and direct-link blocking.
- Added dynamic SPA and infinite-scroll handling.
- Added multilingual navigation fallbacks and localized extension metadata.
- Added safety checks for mixed shelves and recycled YouTube renderers.
- Added automated tests, packaging, and a Firefox performance benchmark.
