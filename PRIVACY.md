# Privacy policy

PantsOnly does not collect, retain, transmit, sell, or share personal
data, browsing history, search terms, analytics, or telemetry.

To perform its single purpose, the extension processes YouTube page structure,
link destinations, and navigation events locally in the browser. This data
never leaves the device and is not stored by the extension. The extension makes
no network requests of its own and has no accounts, advertising, analytics, or
remote code.

An optional local diagnostic mode reads the fixed
`no-youtube-shorts-debug` flag from YouTube's local storage and writes aggregate
element counts to the browser console. It does not read or log other stored
values, page text, URLs, or identifiers.

Questions can be filed in the public repository's issue tracker. This policy
will be updated before any release that changes the extension's data practices.

Last updated: September 10, 2026.
